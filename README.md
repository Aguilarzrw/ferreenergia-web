# Ferreenergía VE – propuesta web

Vite + JS vanilla · Three.js · GSAP/ScrollTrigger · Lenis. Sitio 100% estático.

- `npm run dev` / `npm run build` / `npm run preview`
- Catálogo: `src/data/productos.json` · Calculadora: `src/data/equipos.json`
- Contactos y WhatsApp: `src/js/config.js`
- Fotos reales: `public/img/productos/<id>-1.webp` y declararlas en `imagenes` del producto
- `npm run assets` regenera `og.png` y `apple-touch-icon.png` desde `public/img/logo.svg` (logo provisional)
